# SpeedPlus ⚡ — مشروع سكربتات متعدد الوحدات

سكربت شخصي للعبة **+1 Speed Keyboard Escape | Candy & Chocolate** (Place ID: `95082159892680`)
يعمل عبر **Delta Executor** على الهاتف، ويُشغَّل من رابط Raw مباشر من GitHub.

## 🚀 التشغيل (استخرج ملفاً واحداً فقط)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ilyesguers/Robloxscript/main/SpeedPlus.lua"))()
```

اللودر يجلب الوحدات من `SpeedPlus/` بالترتيب، وأي وحدة تفشل لا توقف الباقي.

## 📁 بنية المشروع (15 وحدة)

```
SpeedPlus.lua          ← اللودر (الملف الوحيد الذي تستخرجه)
SpeedPlus/
├── Config.lua         ← الإعدادات وأسماء الريمونات (نقطة الصيانة)
├── Theme.lua          ← ألوان الحلوى + ألوان كل صفحة
├── Utils.lua          ← أدوات مشتركة (إنشاء/إشعار/بحث ريمونات/تنظيف)
├── UI_Lib.lua         ← مكتبة الواجهة (نافذة + تبويبات + تحكمات متحركة)
├── Pages.lua          ← إنشاء الصفحات الثماني + الرئيسية والإعدادات
├── Background.lua     ← خلفية متحركة (فقاعات + حلوى + نجوم)
├── Aura.lua           ← هالات نابضة (زر عائم + شخصية)
├── HUD.lua            ← شريط الحالة الحي
├── Farm.lua           ← محرك الزراعة (خطوات / تريدميل / هجين)
├── Win.lua            ← محرك الفوز (انزلاق سماوي / فوري / مشي)
├── Economy.lua        ← الاقتصاد (ريبيرث / هدايا / كوبونات)
├── Movement.lua       ← الحركة (سرعة / قفز / Noclip / طيران)
├── Visuals.lua        ← المرئيات (ESP لوحات / تريدميلات / لاعبين)
├── Gravity.lua        ← الجاذبية (Zero-G / قمر / مغناطيس / ثقب أسود)
└── Boot.lua           ← الإقلاع النهائي
```
